# ChuckJokesVue

Proyecto realizado con Vue.js.

## Descripcion

Aplicacion desarrollada con Vue.js para mostrar una lista de chistes de Chuck Norris utilizando la directiva v-for.

## Caracteristicas

- Uso de Vue.js
- Uso de v-for
- Lista dinamica de datos
- Diseño con CSS

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Vue.js
